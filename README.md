# ARC Prize 2026 — Failed in AIMO

**ARC-AGI-2 少样本抽象推理：程序合成 + 测试时自适应，以及一次诚实的失败分析。**

## 1. 赛题理解

ARC-AGI-2 要求从 2–3 个输入/输出示例中推断网格变换规则，并在测试网格上应用。核心难点：

- 规则空间开放（几何、拓扑、颜色、计数、对象组合）；
- 样本极少，无法靠大数据拟合；
- 评测是精确匹配，部分正确不得分。

## 2. 尝试方案

### 2.1 程序合成

- 定义一个小型 DSL（旋转、翻转、转置、裁剪包围盒、填色、缩放）。
- 在 DSL 上做深度 ≤ 3 的组合搜索，用全部训练示例做一致性剪枝。

### 2.2 测试时自适应

- 对每个任务单独训练一个极小的逐像素颜色映射分类器。
- 只在当前任务的示例上拟合，不跨任务共享参数。

### 2.3 集成

- 多个候选程序按训练示例一致性投票；
- 一致性相同时按程序长度优先（Occam）。

## 3. 失败分析（重要）

- **组合规则爆炸**：多步变换串联时，深度 3 的搜索空间已经很大，简单剪枝不够。
- **TTT 过拟合**：2–3 个示例上训练的颜色映射在测试网格上规则漂移，精确匹配失败。
- **对象级规则缺失**：DSL 只覆盖全局几何变换，无法处理「找最大对象并复制」这类结构规则。
- **无学习信号**：精确匹配奖励稀疏，无法给搜索提供梯度式引导。

## 4. 改进方向

- 引入 LLM 生成候选程序 + 符号执行验证的混合范式；
- 增加对象级 DSL（连通域、计数、排序、模板匹配）；
- 用贝叶斯优化替代穷举搜索，按示例一致性做先验更新；
- 测试时训练加入强正则与早停，避免在 2–3 个示例上过拟合。
